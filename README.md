# Assembly

Assembly is pretty easy! It took me a little less than two hours to get everything soldered. 

- LED1 - GPIO11
- LED2 - GPIO12
- LED3 - GPIO13
- LED4 - GPIO14
- LED5 - GPIO15
- LED6 - GPIO0
- OLED SCL - GPIO10
- OLED SDA - GPIO9
